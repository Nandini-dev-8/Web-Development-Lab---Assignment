# Student Expense Tracker 💰

## 📌 About the Project
The Student Expense Tracker is a simple web-based application designed to help students manage and track their daily expenses. It allows users to add expenses, categorize them, view the total amount spent, and filter expenses based on different categories.

## ✨ Features
- **Add Expenses:** Enter an expense name and amount.
- **Category Selection:** Choose from Food, Education, Shopping, Travel, and Other.
- **Total Calculation:** Automatically calculates the total expenses.
- **Filter Expenses:** View expenses based on selected categories.
- **Delete Expenses:** Remove expenses from the list.
- **Input Validation:** Ensures valid expense names and amounts.

## 🛠️ Technologies Used
- HTML5 – Structure of the application.
- CSS3 – Styling and layout.
- JavaScript – Functionality and expense management.

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start adding and managing your expenses!

## 🎯 Project Objective
The main objective of this project is to practice HTML, CSS, and JavaScript concepts while developing a useful application that helps students keep track of their expenses.
